# GeiserX Runtipi App Store

<p><a href="LICENSE"><img src="https://img.shields.io/github/license/GeiserX/runtipi-appstore?style=flat-square" alt="License"></a></p>

Community app store for [Runtipi](https://runtipi.io/) with 16 self-hosted applications by [GeiserX](https://github.com/GeiserX).

## Quick start

1. Open your Runtipi dashboard
2. Go to **Settings > App Stores > Add App Store**
3. Paste this repository URL: `https://github.com/GeiserX/runtipi-appstore`
4. Give it a name (e.g., "GeiserX Apps") and save

Needs Runtipi 4.5.0 or later.
